# ADR-0001 — 双平台执行与 Mac GUI 安全策略

> 2026-10-26 · 状态：`accepted`（由用户在本次会话明确提出的操作边界） · 关联：FEAT-010、FEAT-012。

## 背景

开发者在 Mac 上有持续使用的日常桌面环境，不允许 AI 开发突然弹出项目窗口、编辑器、浏览器或干扰电脑正常使用；Windows 可自由进行项目常规 GUI 调试。

## 决策

- macOS 上 Agent 默认仅执行经审阅的无 GUI 命令行检查；禁止自主启动 Cocos 编辑器、Cocos CLI 构建、微信开发者工具或浏览器。
- **官方文档指出 Cocos CLI 构建也依赖 GUI**，所以不能以终端、后台或 `--headless` 名义绕过。
- Windows 作为主要 Cocos 图形构建、游戏预览、微信开发者工具和真机联调环境。
- 如果缺 Windows 或无法完成可视化检查，明确标记 `blocked` / `not_run`，不虚构完成。
- 特定 Mac GUI 操作须由用户针对**该次操作**明确授权。

## 替代方案及否决原因

- Mac 命令行直接构建：官方已提示依赖 GUI，不符合默认禁止弹窗要求。
- Mac 启动隐藏或最小化窗口：仍有焦点、资源和子进程风险，不能当作安全后台调试。
- 完全不用图形/真机调试：无法验证引擎场景、微信兼容和真实玩法操作。

## 后果及回退

开发节奏需增加跨机验证与真实日志记录；牺牲部分自动化速度，换取日常 Mac 环境可预测性。改变本决策须用户明确批准并同步 `AGENTS.md`、`DEV_ENVIRONMENT.md`、`TESTING.md`、`CHANGELOG.md`。
