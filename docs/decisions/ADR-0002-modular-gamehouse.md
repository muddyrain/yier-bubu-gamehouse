# ADR-0002 — 一体大厅 + 独立小游戏模块

> 2026-10-26 · 状态：`proposed`（选型建议，待 P1 原型验证） · 关联：FEAT-001 至 FEAT-011。

## 背景

产品首发 1 个精品主游戏和 3 个经典小游戏，未来增加合作/对战和更多玩法。若各游戏各自实现登录、角色、存档与奖励，会造成大量维护成本。

## 方案

采用 Cocos Creator + TypeScript，统一 App Shell、角色 ID、游戏生命周期、公共进度及平台适配；单游戏实现独立规则与游戏内进度。P5 新增 RoomService 与不同游戏的 NetworkAdapter，先在黄金矿工验证。

## 替代方案

- 四个独立小程序：更容易隔离但升级、分享、成长和未来房间体验割裂。
- 单个全能 GameManager：初期快，后期难分离规则与内存。
- 一开始设计完整多人框架：当前未验证玩法，抽象很可能失真且增加复杂度。

## 决策依据与待验证

P1 验证两个测试小游戏场景可进出并释放资源；P3 验证塔防与矿工同大厅互不干扰；P5 验证房间共享入口。没有这些证据前，架构为**计划**不是实现。
