# FEAT-007 — 一二布布合成乐园

> FEAT-007 · v1.0 · 2026-10-26 · 所属阶段：P4 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为希望快速玩一局同时积累图鉴的玩家，我希望通过碰撞或放置合成不同级别的角色/物品挑战得分。

## 2. 玩法 / 交互与状态

- 一二和布布共同出现在主题 UI，单人角色选择影响演出/头像但不影响竞分公平。
- 设计 10–12 级原创合成链，通过物理碰撞或确定规则逐级升级。
- 基础无尽得分模式、每日挑战规则和图鉴目标。
- 结束可查看本局分数、最高记录、重新开始或回大厅。

## 3. 范围与非范围

**包含：**

- 合成判定、得分、溢出结束、图鉴存档
- 少量机制变化的每日挑战

**不包含：**

- 照搬现成合成游戏的图案/音频/界面
- 强制联网才能玩

## 4. 数据与依赖

- MergeChainDefinition、MergeRunState、HighScore、CollectionEntry

## 5. 验收标准

- [ ] **AC-01**：相同类型图块正确合并且加分，非法合并无效。
- [ ] **AC-02**：重力与碰撞结果不会重复奖励或陷入无限合并。
- [ ] **AC-03**：结束后保存最高分与图鉴，退出重启可恢复。
- [ ] **AC-04**：一二和布布均可选择，视觉权益对等。
