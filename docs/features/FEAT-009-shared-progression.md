# FEAT-009 — 公共奖励、成就与小屋

> FEAT-009 · v1.0 · 2026-10-26 · 所属阶段：P4 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为玩不同游戏希望有共同积累的玩家，我希望将小目标奖励用于双主角装扮/简单装饰。

## 2. 玩法 / 交互与状态

- 各游戏结算通过统一奖励服务获得饼干币或成就进度。
- 饼干币用于非必需的外观、图鉴和小屋物品，不作为主线付费/强制刷取门槛。
- 小屋中一二与布布都可以展示/穿戴已获得道具。
- 奖励不应重复领取或因崩溃重复发放。

## 3. 范围与非范围

**包含：**

- 奖励账本、有限成就、基础装扮或小屋占位
- 本地保存和防重复发放规则

**不包含：**

- P4 在线交易、充值、复杂商城或商业活动后台
- 购买玩法必需关卡权限

## 4. 数据与依赖

- RewardEventId、CookieBalance、AchievementId、CosmeticId

## 5. 验收标准

- [ ] **AC-01**：相同结算事件重复调用不能重复发奖励。
- [ ] **AC-02**：至少塔防与黄金矿工都能进入公共奖励流程。
- [ ] **AC-03**：一二与布布都有展示入口，无角色排他道具造成首发不平等。
- [ ] **AC-04**：关闭重开后奖励与购买状态不丢失。
