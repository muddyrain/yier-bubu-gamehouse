# FEAT-001 — 游戏大厅与目录

> FEAT-001 · v1.6 · 2026-10-28 · 所属阶段：P1 · 负责人：待定。**实施状态只在 `docs/FEATURES.md` 维护。** P1-02 专项已通过最终复审并获用户验收；完整 AC-03 仍待 FEAT-003，Feature 不标 done。

## 1. 目标与用户故事

作为首次打开游戏的玩家，我希望直观看到一二与布布、选择游戏并能从任何游戏返回大厅。

## 2. 玩法 / 交互与状态

- 大厅同时展示一二（白熊）和布布（棕熊），不存在默认只有布布的主视觉。
- 按 [ADR-0003](../decisions/ADR-0003-landscape-first.md) 采用 1280×720 横屏设计基准，双角色与目录布局须覆盖不同宽高比和安全区；不在切换游戏时旋转。
- 游戏目录显示四款首发游戏；未开发的入口清楚标注“开发中”，不能点击后报错。
- P1-02 四款均为 `coming-soon`：tower-defense / 一二布布守护小屋、gold-miner / 一二布布黄金矿工、merge / 一二布布合成乐园、snake / 一二布布贪吃蛇；显示名与稳定 ID 分离。点击只显示介绍及“开发中”，不加载不存在的游戏。
- 独立 `Lobby.scene` 使用同规格白/棕程序几何头像、名称和双主角区域。Startup/SmokeTest 继续作为 P1-01 回归入口，不承载正式大厅 UI。
- 大厅只允许一个提示面板：游戏介绍、帮助、当前设置说明、好友预告；关闭或 Escape 返回原大厅。重复打开复用同一节点，不为每次打开新增事件订阅。无存档时不显示继续按钮，明确说明暂无可继续的存档。
- 好友入口标注“敬请期待”，不触发房间、微信登录、分享或选角。设置只说明当前无音效/音乐及可调整项，不制作假开关。
- 进入某款游戏前进入统一选角/模式步骤，完成或退出后回到大厅。
- 后台切回或再次启动时恢复合理的大厅状态，不重复创建游戏实例。

## 3. 范围与非范围

**包含：**

- 大厅入口、游戏卡、继续游戏、设置、功能占位说明、退出导航
- 首发阶段可用简单 UI，不要求完整 3D 小屋
- P1-02 为独立大厅、四卡目录、双主角展示和可逆提示；数据/导航纯逻辑与引擎视图分开。后续真实选角/游戏加载在对应 Feature 接入，不提前设置 implemented 或制造局内会话。

**不包含：**

- 自动匹配陌生人
- 在 P1 中实现所有小屋装修动画
- P1-01 的 `Startup.scene` 仅作工程启动测试，不是本 Feature 的正式大厅；双角色矩形占位不等于完成目录、选角或返回流程。
- 本轮不实现 FEAT-002 真选角、FEAT-003 场景往返、存档、可玩小游戏或联机。下面 AC-03 继续留待 FEAT-003 集成，不以提示面板的返回替代。

## 4. 数据与依赖

- GameId / GameCatalogEntry
- GameModuleRegistry 接口由 FEAT-003 定义
- 角色选择依赖 FEAT-002
- 当前仅 LobbyModel 中的只读目录/角色身份、单面板导航与设计布局；LobbyView 持有 UI 节点和订阅。没有 GameModuleRegistry、GameSession 或 RoomService 的伪实现。

## 5. 验收标准

- [x] **AC-01**：首页同时正确出现一二和布布，角色视觉/名称无颠倒。
- [x] **AC-02**：四款首发卡片都有准确名称与 implemented/coming-soon 状态。
- [ ] **AC-03**：可从进入后的游戏/测试场景返回，不残留多余场景实例或音频。
- [x] **AC-04**：未实现卡片不会假装可玩，给予准确提示。
- [x] **AC-05**：游戏/帮助/设置/好友提示连续打开和关闭至少三次，无叠加面板、重复回调或不可返回状态；纯逻辑与真实引擎分别验证。

## 6. 验证方法

| 环境 | 具体验证 | 目前状态 |
| --- | --- | --- |
| macOS CLI（需事先审核无 GUI） | 安全入口执行目录/身份/导航/布局逻辑及资源引用检查；需要现有 Node/TypeScript，缺引擎声明的 typecheck 阻塞 | `not_run`，未在 Mac 实机执行 |
| Windows CLI | 同一目录/导航/布局逻辑、13 项原回归及新增资源引用、TypeScript 检查 | `passed`，15 unittest（内含 9 组纯模型断言）及 tsc，见最新报告 |
| Windows 编辑器导入 | 3.8.8 打开 Lobby、识别 LobbyView，Meta imported=true 且 UUID 保留 | `passed`，只代表导入/识别，不代表运行 |
| Windows GUI 运行 | 三比例画面、七入口各三次、键盘/遮罩、组件恢复和再次预览 | `passed`，画布聚焦后的键盘由独立可视本地预览验证；原失败与退出诊断见最新报告 |
| 微信真机（需要时） | 启动后布局/触控与安全区域检查 | `not_run` |

**Mac 禁止擅自启动 Cocos、浏览器、微信开发者工具或 GUI 调试。** 未验证部分始终记 `not_run` 或 `blocked`，不能因写完本 Feature 就标通过。
