# FEAT-006 — 一二布布黄金矿工

> FEAT-006 · v1.0 · 2026-10-26 · 所属阶段：P3 / P4 / P5 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为喜欢抓钩与关卡经营的玩家，我希望选一二或布布探索矿洞、赚取资源并升级工具。

## 2. 玩法 / 交互与状态

- 单人选角后控制抓钩摆动、出钩、抓取、计分、倒计时。
- P3 制作 10 关垂直切片，覆盖普通矿物、障碍、一个新机制；P4 扩至 30 关及升级循环。
- 同主题的游戏封面呈现一二和布布；单人不固定布布为唯一矿工。
- P5 首个联机试点：一人一只熊，各控制抓钩协作挖矿，服务端判定抓取归属和得分。

## 3. 范围与非范围

**包含：**

- 抓钩物理/逻辑、矿物价值、关卡目标、升级、结算
- 双人兼容规则设计（P5 实装）

**不包含：**

- 复制既有游戏关卡/图像/音效
- P3 直接开发好友房真实服务器

## 4. 数据与依赖

- GoldMinerLevel、MinerToolUpgrade、RoundScore
- 单机存档与 P5 RoomSession

## 5. 验收标准

- [ ] **AC-01**：P3 10 关的关卡配置可编辑，不靠硬编码切场景。
- [ ] **AC-02**：基础抓取、失败超时、成功结算和升级循环完整。
- [ ] **AC-03**：一二和布布都能作为矿工正常进入、操作与计分。
- [ ] **AC-04**：与塔防来回切换 3 次，进度无互相覆盖。
- [ ] **AC-05**：P5 有双手机协作回归测试，抓同一矿物不会被奖励两次。
