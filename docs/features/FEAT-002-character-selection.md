# FEAT-002 — 一二与布布选角

> FEAT-002 · v1.0 · 2026-10-26 · 所属阶段：P1 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为任意游戏的单人玩家和未来好友房的两名玩家，我希望自由选择一二或布布作为自己控制的角色。

## 2. 玩法 / 交互与状态

- 一二是小白熊（ID `yier`），布布是小棕熊（ID `bubu`），两个角色界面权重、可用性完全对等。
- 单人默认先选择角色；主题名称《黄金矿工》等不限制选一二或布布。
- 在游戏外可更改下一局的角色；局内是否允许更换由对应游戏规定。
- P5 房间中角色默认互斥，两个玩家不能抢同一角色。

## 3. 范围与非范围

**包含：**

- 角色数据、选择组件、显示名、头像占位、进入会话时透传 CharacterId
- 单人角色偏好可按设计持久化

**不包含：**

- 不受权属保护的网络角色图直接商用
- 在 P1 开发好友联机选角服务

## 4. 数据与依赖

- CharacterId = yier | bubu，稳定 ID，不与本地化显示文字混用
- GameSession.selectedCharacter
- 房间中由服务端确认 selectedCharacter，详见 FEAT-011

## 5. 验收标准

- [ ] **AC-01**：两只熊身份、颜色和名称正确且在 UI 中平等展示。
- [ ] **AC-02**：一二和布布任意一只都能从选角进入同一可用游戏原型。
- [ ] **AC-03**：非法 CharacterId 被安全拒绝/回退，不造成崩溃。
- [ ] **AC-04**：重新进入选角时状态符合设计，不误把布布自动设置为唯一角色。
