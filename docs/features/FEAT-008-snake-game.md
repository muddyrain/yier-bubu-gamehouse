# FEAT-008 — 一二布布贪吃蛇

> FEAT-008 · v1.1 · 2026-10-26 · 所属阶段：P4 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为希望短局冲分和反复挑战的玩家，我希望以一二或布布为蛇头，吃零食、躲障碍、挑战个人记录。

## 2. 玩法 / 交互与状态

- 单人选择一二或布布作为蛇头，移动/转向操作适合手机触屏。
- 棋盘与输入区采用 [ADR-0003](../decisions/ADR-0003-landscape-first.md) 的横屏基准，保持格子比例；实际可见格数和触控区域随设备验证，不动态旋转。
- 基础经典模式与至少一种机关地图变化（如传送门/变换障碍，P4 以实测确定）。
- 出界/碰撞/胜利或失败有清晰结算，支持立刻再来一局。
- 未来可扩展双人同图对战，但 P4 不强制联网。

## 3. 范围与非范围

**包含：**

- 可预测的移动 Tick、转向限制、食物刷新、计分与障碍
- 个人最佳和挑战记录

**不包含：**

- P4 直接实时联机对战
- 隐藏玩家状态以增加难度

## 4. 数据与依赖

- SnakeState、BoardState、DirectionInput、BestScore

## 5. 验收标准

- [ ] **AC-01**：蛇头和蛇身移动规则确定可测试，不允许非法 180 度反向。
- [ ] **AC-02**：食物不会出生在不可用格或角色身体中。
- [ ] **AC-03**：一二/布布均可选，碰撞规则公平。
- [ ] **AC-04**：失败后能重玩，个人最高纪录正常保存。
