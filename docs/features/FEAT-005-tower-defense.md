# FEAT-005 — 一二布布守护小屋（精品塔防）

> FEAT-005 · v1.2 · 2026-10-30 · 所属阶段：P2 / P4 · 负责人：待定。**实施状态以 `docs/FEATURES.md` 为准，当前为计划方案。**

## 1. 目标与用户故事

作为想连续闯关并研究阵容的玩家，我希望与一二和布布一起守护小屋，在不同关卡通过策略取胜。

## 2. 玩法 / 交互与状态

- 以 1280×720 横屏触控为设计基准，按 [ADR-0003](../decisions/ADR-0003-landscape-first.md) 安排战场和操作区；玩家选一二或布布，另一只以伙伴身份参与视觉或系统表现。具体安全区和触控仍需真机验证。
- 放置原创防御机关、抵挡敌人波次、依据关卡规则结算胜负。
- P1-04 完成后，先做一张完整森林小屋战斗地图、一个可完成关卡的精致可玩垂直切片；通过实际试玩后再扩到 P2 的 5 关和 P4 的首发目标 24 关。
- 具备重试、通关评价、解锁新防御道具、可选重复挑战；未来支持双人协作。

## 3. 范围与非范围

### 第一版：先完成一个关卡

- 一张完整森林小屋战斗地图；两种有清楚用途区别的防御单位；两种可辨识敌人，三波进攻。
- 玩家可放置防御，单位实际攻击；敌人、单位或小屋按玩法具有明确生命值与受击反馈；三波结束可胜利，小屋生命耗尽可失败，两种结局均可重试。
- 一二或布布均能进入和完成同一关卡。统一高品质 2D UI、地图与单位的美术方向，具备选择/放置、攻击/受击、波次和胜负反馈；优先用真实运行画面和操作检验效果。
- 正式角色以原作者形象为标准。原稿与可用许可取得前沿用明确的开发占位，不把自行设计的相似熊作为最终正式角色；地图、单位与 UI 只使用自制或已获许可素材。
- 这一版不以永久存档、公共奖励、更多关卡、联机或通用架构扩建为前置；相关完整 Feature 验收仍保留，不因单关可玩提前宣称通过。

**包含：**

- 独创的敌人/防御/关卡数据、资源与数值平衡
- 通关存档、战斗暂停与结算

**不包含：**

- 照搬《植物大战僵尸》的具体关卡或美术
- P2 直接制作全部 24 关或网络联机

## 5. 验收标准

- [ ] **AC-01**：至少 5 关 P2 垂直切片可连续通关，含一关明显改变策略的机制。
- [ ] **AC-02**：敌人出场、目标判定、资源消耗和输赢结果可被纯逻辑测试覆盖。
- [ ] **AC-03**：选择一二或布布均能完成单人战斗，不存在角色被禁用。
- [ ] **AC-04**：退出后返回大厅无残留战斗逻辑，恢复已结算关卡记录。
- [ ] **AC-05**：P4 扩展关卡必须保持数据驱动并经过玩家试玩/难度审查。
- [ ] **AC-06**：第一版在真实 Cocos 运行中显示完整森林小屋地图，含两种防御单位、两种敌人和实际三波进攻，可通过操作完成一个关卡。
- [ ] **AC-07**：第一版攻击与生命变化可观察，胜利/失败和重试均可实际触发；选一二或布布均可游玩，不依赖永久存档或公共奖励。
- [ ] **AC-08**：第一版真实截图与试玩展示统一的 2D UI 和美术方向，选择/放置、攻击/受击、波次和结算有可辨识反馈；角色占位与正式原稿/许可边界清楚。
