# 本机开发环境保护与测试执行红线

> DOC-ENV · v1.0 · 2026-10-26 · 本文是 `AGENTS.md` 的详细强制规则。**macOS 不允许影响日常使用体验**。

## A. 判定原则

1. **先识别系统**，无法确认则以 macOS 严格策略处理；远端 Windows 须确认确实在 Windows 机器执行，不能把 Mac 上的虚拟/子进程随意当作 Windows 放宽规则。
2. **先分类命令**：是否可能间接启动 GUI、打开系统提示、抢焦点、访问用户屏幕、占用高 CPU/GPU、影响全局配置或无关进程。若不确定，不执行。
3. **Mac 默认 GUI 禁止**。即使号称 `--headless`、后台、隐藏窗口、命令行，**必须证明工具及其子进程完全不涉及 GUI，才能执行**。Cocos 3.8 的命令行构建官方明确需要 GUI 环境，因此默认禁止。
4. Windows 允许 GUI 开发/调试，但不等于允许危险的系统操作或上传私人数据。
5. 用户仅对**某次具体操作**明确许可 Mac GUI 时，记录目的、窗口范围、退出与清理；许可不延续到后续任务。

## B. 系统行为矩阵

| 操作 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| 读取项目文件、`git status/diff` | ✅ | ✅ |
| 纯 TS 类型检查、Lint、单元测试（脚本与子进程审计后） | ✅ | ✅ |
| 受控短时 CLI 资源/文档扫描 | ✅ | ✅ |
| `npm install`、`postinstall` 或未审阅脚本 | ⛔先审阅、必要时经用户授权 | ✅可用但审阅危险脚本 |
| Cocos Creator GUI 编辑/预览 | ⛔ | ✅ |
| Cocos Creator **命令行构建**（依赖 GUI） | ⛔ | ✅ |
| 微信开发者工具、网页预览、模拟器 | ⛔ | ✅ |
| 浏览器自动化、Playwright/Electron GUI、截图录屏 | ⛔ | ✅ |
| 系统级安装、权限授予、全局配置变更 | ⛔ | ⚠️需明确授权 |
| 杀进程/清理非本任务文件 | ⛔ | ⛔ |

标记：✅ 可在任务授权范围内执行；⛔ 默认不可执行；⚠️ 仍需另行授权。

## C. macOS 允许的“后台调试”到底是什么

- **指纯命令行、无界面的逻辑检查**，例如 TypeScript 类型检查、单元测试、关卡配置校验、资源元数据校验、文档链接检查、Git diff 检查。可以在不抢占窗口的终端/远程执行环境运行。
- 默认**不要启动长期常驻后台服务**。优先采用前台阻塞且有超时的 CLI 子进程，日志写入项目下 `.local/validation/`，进程退出后再汇报。用户正常使用电脑不应被打断。
- 资源策略：避免无上限并行、持续占用 CPU/GPU 的测试；测试时设合理超时（P1 确定预算，当前未验证具体数字），遇到明显负载异常停止**本次任务拥有**的进程，绝不 `killall` 或按名称杀死其他进程。
- 界面、视觉、真实交互、微信模拟器/真机不属于 Mac 默认后台验证。没有 Windows 验证时标 `not_run/blocked`，不承诺视觉正确。

## D. macOS 禁止的常见触发器（举例，不是完整黑名单）

- `open`, `open -a`, `osascript`, `screencapture`, `CocosCreator.app` 的编辑器/构建/预览调用；可能唤起窗口的 `npm run dev`、`npm run preview`、`npm run build` 以及未知脚本。
- 微信开发者工具、任何 GUI 自动点击/录屏、模拟鼠标键盘、浏览器启动脚本、浏览器调试插件、Playwright/Puppeteer/Chromium（即便声称 headless，未经审阅也不行）。
- 自动安装、升级全局 Node/Cocos/浏览器，改系统偏好设置，覆盖 Shell startup、设置开机启动，绕过 macOS 安全提示。
- 通过 `nohup`、`&`、`launchctl`、隐藏窗口启动 GUI 并声称“对用户无影响”。

## E. Windows 正常调试范围

允许按 Issue 需要启动 Cocos、微信开发者工具、浏览器、截图、真机联调、网络日志和性能分析，能主动弹出相应项目的调试窗口。调试完关闭**本轮创建**的窗口和进程，保护用户现有开发环境；任何模拟器/调试用账号不得影响真实用户数据。

## F. 任务前安全检查记录（示例字段）

```text
OS: macOS / Windows / unknown
本次授权范围: [Issue 编号和动作]
拟执行命令: [逐条列出真实命令]
是否调用 GUI/浏览器/构建器/截图: yes/no/unknown
依赖脚本是否已审阅: yes/no
可能改动的路径: [...]
超时与日志位置: [...]
执行决定: run / do-not-run / move-to-windows
```

## G. 验证记录用词

只能写 `passed`（真实通过）、`failed`（真实失败）、`not_run`（未执行）、`blocked`（阻塞）。不同平台分别记证据。**macOS 的类型检查 passed 不等于 Windows 的游戏启动 passed。**

## H. 与 Cocos 官方文档的关系

官方 3.8 命令行发布文档明确“仍需要 GUI 环境”；微信小游戏发布向导的“运行”会唤起微信开发者工具。本项目据此把引擎构建和可视化调试放到 Windows。来源详见 `docs/REFERENCES.md`。
